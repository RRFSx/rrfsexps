# exp_depot
Collection of exp and configuration files from ar-worklfow, rrfs-workflow, rtma-workflow, etc.    
**NOTE**: All exp files in this repo are examples, not necessarily up-to-the-date. Compare them with the official ones in the latest workflow before setting up an experiment.

1. All are welcome to create PRs and commit their exp setup files to this repo.   

2. Either create subdirectories by user names, such as `user-Guoqing/`, `user-Chunhua/`, `user-EricJames/`, etc,     
or by groups, such as `dev1/`, `dev2/`, `chemistry/`, `coldstart_only` etc

3. If there is an `config_chemistry` file, commit it as well.    
Here is an example: https://github.com/AR-PS/exp_depot/tree/main/chemistry/smoke_dust_conus12km

4. If there is an `config_resources/config_override` file, commit it as well

5. It is welcome to use wiki pages to add more details about a given experiment.
